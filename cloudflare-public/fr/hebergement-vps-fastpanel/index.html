L’hébergement VPS avec FASTPANEL associe un VPS autogéré à un panneau d’hébergement web pour les sites, domaines, bases de données, PHP, SSL, la messagerie, les sauvegardes et les tâches planifiées. Le panneau simplifie l’administration courante, mais le VPS doit être dimensionné pour FASTPANEL ainsi que les sites et services qu’il héberge.

VDSina répertorie actuellement FASTPANEL sur Ubuntu 22 comme une option de déploiement de panneau de contrôle d'hébergement Web sur son VPS standard. C'est un choix de déploiement de fournisseur, pas une revendication que le serveur devient entièrement géré.

Pour le choix du serveur dans son ensemble, consultez VPS pour site web. Pour le choix général d’un panneau, consultez VPS avec panneau de contrôle.

FASTPANEL sur VDSina

La page VPS actuelle de VDSina Standard répertorie FASTPANEL sous Panneau de contrôle d'hébergement Web avec Ubuntu 22.

Cela donne à cette page un chemin de déploiement spécifique :

  1. choisir les ressources du VPS selon la charge du site web ;
  2. sélectionnez l’option FASTPANEL / Ubuntu 22 du fournisseur où elle est actuellement offerte;
  3. terminer la configuration du panneau et du site ;
  4. tester le site Web avant d'envoyer du trafic de production;
  5. surveiller l'utilisation réelle des ressources après le déploiement.

Ne supposez pas que l’option FASTPANEL du fournisseur inclut l’administration du serveur. La différence entre assistance à l’infrastructure et administration continue est expliquée dans VPS infogéré ou non infogéré.

Configuration requise pour FASTPANEL et dimensionnement réel d’un site web

La documentation officielle d’installation manuelle de FASTPANEL indique actuellement un minimum de :

  • 1 GB de RAM;
  • 5 GB d’espace disque libre ;
  • 1 cœur CPU / 1 GHz ;
  • un système d'exploitation 64 bits compatible propre;
  • Accès root.

Il s’agit des minimums nécessaires à l’installation du panneau. Ils ne constituent pas une recommandation de dimensionnement de production pour un VPS qui exécute aussi :

La documentation d'installation manuelle actuelle de FASTPANEL répertorie ces systèmes d'exploitation 64 bits pris en charge : Debian 9/10/11/12, Ubuntu 18.04/20.04/22.04/24.04, CentOS 7, AlmaLinux 8 et Rocky Linux 8. L'installation manuelle nécessite un système d'exploitation propre. Cette liste de support FASTPANEL plus large est distincte de l'option préconfigurée actuelle de VDSina, qui est spécifiquement répertoriée comme FASTPANEL sur Ubuntu 22.

  • Nginx/Apache ou d’autres services web ;
  • PHP-FPM ou un autre environnement d'exécution ;
  • MySQL / MariaDB / PostgreSQL;
  • WordPress ou un autre CMS ;
  • services de messagerie ;
  • filtrage anti-spam;
  • sauvegardes;
  • tâches cron;
  • supervision ;
  • plusieurs sites et utilisateurs.

Un serveur peut respecter le minimum requis par le panneau tout en manquant de marge pour le site web.

Un budget RAM pratique

Pensez aux composants :

RAM nécessaire = système d’exploitation + services FASTPANEL + pile web + base de données + processus applicatifs + messagerie/cache/tâches de fond + marge

Par exemple, un site WordPress d'entreprise peut avoir besoin de place pour le système d'exploitation, FASTPANEL, MySQL/MariaDB, plusieurs processus PHP, des tâches cron et une activité de sauvegarde en même temps. C'est pourquoi 4 GB est souvent un point de départ plus pratique que de traiter 1 GB comme cible de production par défaut.

Ce que FASTPANEL gère

Le site officiel actuel et la documentation de FASTPANEL exposent les fonctions de gestion de l'hébergement, notamment:

  • création de site web;
  • domaines et alias ;
  • droits d’accès et utilisateurs ;
  • Paramètres PHP et plusieurs versions de PHP;
  • bases de données;
  • Certificats SSL et redirections HTTPS ;
  • boîtes aux lettres, alias et redirection;
  • gestion des fichiers ;
  • règles de pare-feu;
  • plans de sauvegarde ;
  • cron / planification des tâches;
  • statistiques de charge du serveur en temps réel.

L’assistant de création de site peut créer des sites PHP, Node.js, statiques, utilisant un proxy inverse ou gérés par systemd, et peut installer automatiquement WordPress.

Cela rend FASTPANEL utile lorsque vous voulez une interface orientée hébergement au lieu d'effectuer chaque tâche de site de routine manuellement sur SSH.

Ce que FASTPANEL ne gère pas pour vous

Un panneau de contrôle n'est pas la même chose qu'un VPS infogéré.

FASTPANEL ne dispense pas de désigner les responsables des tâches suivantes :

  • les mises à jour du système d'exploitation;
  • sécurité root/SSH;
  • durcissement au niveau du serveur;
  • le suivi des ressources et les décisions en matière de capacité;
  • tests de restauration des sauvegardes ;
  • les vulnérabilités applicatives/plugin ;
  • problèmes de performances des bases de données;
  • la réponse aux incidents;
  • reprise après une mise à jour échouée ou la compromission d’un site.

Utilisez le panneau comme un outil d'administration, pas comme un substitut pour un opérateur.

Consultez VPS infogéré ou non infogéré pour la répartition des responsabilités.

FASTPANEL vs pas de panneau de contrôle

FASTPANEL est utile lorsque vous souhaitez que les tâches d'hébergement de routine soient exposées via une interface Web.

Un VPS Linux vierge sans panneau convient mieux lorsque :

  • vous voulez une pile minimale;
  • vous êtes à l'aise avec la gestion manuelle de Nginx/Apache, de l'environnement PHP/exécution, des bases de données et des certificats ;
  • les services et fonctions du panneau consommeraient inutilement des ressources ;
  • vous avez besoin d’une pile logicielle personnalisée qui ne correspond pas aux hypothèses du panneau;
  • L'infrastructure en tant que code ou l'automatisation personnalisée est votre modèle d'exploitation préféré.

Ne créez pas deux pages concurrentes pour cette décision. Le déploiement manuel au sens large relève de Comment héberger un site web sur un VPS ; le choix général d’un panneau reste traité dans VPS avec panneau de contrôle.

FASTPANEL vs autres panneaux de contrôle

Choisissez FASTPANEL parce que son flux de travail s'adapte à votre pile et à votre modèle d'exploitation, pas parce que chaque panneau résout le même problème.

Comparer les panneaux sur:

  • systèmes d'exploitation pris en charge et versions;
  • coût de la licence et conditions commerciales;
  • PHP / environnement d'exécution et support de base de données;
  • les exigences en matière de courrier;
  • destinations des sauvegardes et procédure de restauration ;
  • isolation multi-utilisateurs / revendeur / client;
  • l'outillage de migration;
  • maîtrise de l’outil par l’équipe ;
  • documentation et assistance ;
  • Combien de travail manuel SSH / root reste-t-il.

FASTPANEL est attrayant lorsque vous voulez son flux de travail d'hébergement spécifique, son ensemble de fonctionnalités actuelles et son modèle multi-utilisateurs. cPanel, Plesk, HestiaCP et d'autres panneaux ont des compromis différents en matière de licences, d'écosystème et d'administration.

Pour choisir un panneau de manière générale, au-delà du cas FASTPANEL, consultez VPS avec panneau de contrôle.

Créer le premier site web

Une séquence de premier site utile est:

  1. provisionner le VPS avec l'option de déploiement FASTPANEL actuelle ou installer FASTPANEL sur un système d'exploitation propre ;
  2. se connecter et sécuriser le compte administratif ;
  3. créer le site avec l’Assistant Création de Site ;
  4. assigner le domaine;
  5. choisir l’environnement de backend/exécution ;
  6. créer ou joindre la base de données;
  7. configurer les paramètres PHP/application ;
  8. configurer HTTPS;
  9. déployer l’application ou utiliser l’installation automatique de CMS, le cas échéant;
  10. tester le site avant la bascule du DNS public ;
  11. configurer la sauvegarde et la surveillance;
  12. envoyer le trafic de production seulement après que l'application fonctionne sous le vrai nom d'hôte.

Cette procédure est propre à FASTPANEL. Pour le processus complet de migration et de bascule, consultez Migration d’un site web vers un VPS.

WordPress sur FASTPANEL

La documentation officielle de FASTPANEL supporte deux chemins WordPress :

  • installation automatique de CMS via l’assistant de création de site ;
  • Installation manuelle de WordPress après la création du site.

L’assistant WordPress gère la connexion au domaine, les paramètres CMS et les informations d’identification de l’utilisateur du serveur du site.

Cette commodité ne change pas la charge de travail WordPress elle-même. Les processus PHP, les plugins, les requêtes de base de données, la mise en cache, wp-cron et les tâches en arrière-plan déterminent toujours la quantité de CPU / RAM dont le VPS a besoin.

Pour cette charge de travail, voir VPS pour WordPress .

Plusieurs sites Web et isolement des utilisateurs

FASTPANEL est multiutilisateur. Ses recommandations officielles de sécurité préconisent d’héberger les sites distincts sur des comptes utilisateurs FASTPANEL séparés, afin qu’une compromission se propage moins facilement aux autres sites partageant le même compte.

Ceci est particulièrement pertinent pour:

  • les agences;
  • les sites Web des clients;
  • projets non liés;
  • des sites avec différents administrateurs ;
  • charges présentant différents niveaux de confiance.

Les utilisateurs séparés améliorent l'isolation compte / fichier, mais chaque site partage toujours le CPU VPS sous-jacent, la RAM, le disque et le domaine de défaillance.

Pour planifier les ressources cumulées et le périmètre d’impact d’un incident, consultez VPS pour plusieurs sites web.

Email, bases de données, SSL et sauvegardes

Messagerie

FASTPANEL peut gérer les boîtes aux lettres, les alias et le transfert. Si le courrier s'exécute sur le même VPS, budgétisez la RAM, le CPU, le disque et la capacité de sauvegarde supplémentaires pour les services de messagerie et le filtrage anti-spam.

Ne supposez pas qu’une messagerie autohébergée soit l’architecture la plus simple. Une messagerie gérée peut réduire le travail lié à la délivrabilité et à l’exploitation.

Bases de données

FASTPANEL prend en charge la gestion de base de données pour MySQL/MariaDB et PostgreSQL. La charge de travail de base de données peut devenir le goulot d'étranglement du dimensionnement des ressources même lorsque le panneau lui-même est léger.

Surveillez la mémoire de base de données, les requêtes lentes, la latence du stockage et le travail simultané des applications.

SSL

FASTPANEL peut gérer les paramètres et les certificats HTTPS. Confirmez que le domaine réel fonctionne sur HTTPS avant la bascule de production ; un test IP uniquement ne suffit pas.

Sauvegardes

FASTPANEL fournit des plans de sauvegarde et prend en charge les workflows de sauvegarde locaux / distants. Sa propre documentation recommande un stockage sur serveur séparé pour les sauvegardes.

Une sauvegarde de panneau ne doit pas être traitée comme la seule copie de récupération. Conservez une stratégie de récupération indépendante et testez les restaurations.

Sécurité et mises à jour

Utilisez la commodité de FASTPANEL sans affaiblir le modèle de sécurité VPS sous-jacent.

Au minimum :

  • utiliser des informations d'identification uniques fortes;
  • tenir FASTPANEL et le système d'exploitation à jour;
  • restreindre l'accès administratif;
  • séparer les sites Web non liés en différents utilisateurs;
  • revoir les règles du pare-feu;
  • tenir à jour le logiciel de site Web/CMS/plugin;
  • vérifier les tâches de sauvegarde;
  • tester la restauration ;
  • surveiller la pression des ressources et la disponibilité du site Web.

Les directives officielles FASTPANEL recommandent explicitement des comptes utilisateurs séparés pour des sites distincts.

Quand FASTPANEL n’est pas le bon choix

Choisissez un autre chemin lorsque :

  • vous voulez une pile Linux minimale complètement manuelle;
  • l’application nécessite un système d’exploitation non pris en charge ou une organisation du serveur incompatible ;
  • les ressources consommées et les fonctions du panneau apportent peu de valeur à cette charge ;
  • vous avez besoin d’une liberté de configuration qui entre en conflit avec la pile gérée du panneau ;
  • vous avez réellement besoin d'un fournisseur ou d'un administrateur pour faire fonctionner le serveur pour vous plutôt que simplement un panneau de contrôle;
  • Une plate-forme d'application gérée réduirait plus de travail opérationnel qu'un VPS autogéré.

FASTPANEL est le plus fort lorsque l'exigence est contrôle VPS auto-géré avec une interface orientée hébergement , et non lorsque l'exigence est "quelqu'un d'autre doit faire fonctionner le serveur."

FAQ

Qu’est-ce que l’hébergement VPS avec FASTPANEL ?

Il s’agit d’un VPS utilisant FASTPANEL comme panneau de contrôle d’hébergement. FASTPANEL fournit une interface web pour les tâches courantes concernant les sites, domaines, bases de données, PHP, SSL, la messagerie, les sauvegardes et la planification, tandis que le VPS reste votre environnement serveur.

De combien de RAM FASTPANEL a-t-il besoin ?

Le minimum d'installation manuelle officiel de FASTPANEL est actuellement de 1 GB de RAM. C'est le minimum du panneau, pas une recommandation pour la pile complète du site Web de production. Le site Web, la base de données, les processus PHP / application, le courrier et les sauvegardes ont besoin d'une marge de capacité supplémentaire.

1 GB de RAM est-il suffisant pour FASTPANEL et WordPress ?

Cela peut satisfaire le minimum publié du panneau et convenir à une installation de test ou très légère, mais laisse peu de marge. Un VPS de 2 GB constitue un point de départ léger plus réaliste, tandis que 4 GB offre une base pratique plus solide pour une charge WordPress professionnelle.

Est-ce que VDSina offre FASTPANEL?

La page VPS Standard actuelle de VDSina propose FASTPANEL sur Ubuntu 22 parmi ses options de panneau d’hébergement web. Vérifiez l’écran de commande actuel avant l’achat, car les modèles disponibles peuvent changer.

FASTPANEL est-il gratuit ?

Le site officiel actuel de FASTPANEL présente le panneau de contrôle gratuitement. Son flux d'installation manuelle demande toujours une licence lors de la première connexion, alors vérifiez les conditions de licence actuelles et toutes les conditions spécifiques au fournisseur avant le déploiement.

FASTPANEL gère-t-il le VPS ?

Non. Un panneau de contrôle simplifie les tâches d’administration, mais la sécurité continue du système, la supervision, la validation des restaurations, la maintenance applicative et la prise en charge des incidents nécessitent toujours un administrateur, sauf si un service de gestion distinct les couvre.

FASTPANEL peut-il héberger plusieurs sites Web?

Oui. FASTPANEL est multiutilisateur et peut gérer plusieurs sites. Ses recommandations officielles de sécurité préconisent des comptes FASTPANEL distincts pour les différents sites afin de réduire le risque de compromission entre sites.

FASTPANEL peut-il installer WordPress ?

Oui. Son Assistant de création de site prend actuellement en charge l’installation automatique de WordPress, et l’installation manuelle de WordPress est également documentée.

Ai-je encore besoin de SSH avec FASTPANEL?

Souvent, oui. De nombreuses tâches courantes d’hébergement se traitent dans le panneau, mais le dépannage au niveau root, la maintenance du système, les logiciels personnalisés, les journaux et certaines opérations de récupération peuvent encore nécessiter SSH.

Les sauvegardes doivent-elles rester sur le même VPS ?

Pas comme seule copie de récupération. FASTPANEL prend en charge les plans de sauvegarde, mais sa propre documentation recommande un stockage sur serveur séparé pour les sauvegardes. Conservez une copie de récupération indépendante et vérifiez que les restaurations fonctionnent.
