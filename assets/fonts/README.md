Locally served Inter (400–700) and Fraunces (600–700), from the Google Fonts Latin WOFF2 files already used by this site. Original SIL Open Font Licenses accompany each family.

The files retain Latin/Latin-1 (including Spanish accents and punctuation), common typographic punctuation, ligatures, and the needed weight range. They were subset using fontTools 4.x. Other scripts use the CSS fallback until the font set is deliberately extended for that language.

local-fonts.html emits fingerprinted URLs and preloads these two faces. font-display:optional prevents a late font swap from moving page content on slow connections; the text remains readable with fallback fonts if a face is not ready at first render.
