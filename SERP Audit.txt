==================================================
STANDARD WORKFLOW FOR EVERY PAGE
==================================================

Before building any new page:

1. Run a fresh current SERP.
2. Record 8–10 representative competitors/results.
3. Identify primary intent and secondary intents.
4. Check overlap against homepage and already-built pages.
5. Find powerful content/utility gaps.
6. Fix the exact primary keyword.
7. Apply project rule:
   Title = exact primary query
   H1 = exact same text
   URL = same phrase in URL form
8. Build complete page — do not publish an empty shell.
9. Add contextual internal links:
   - one natural link to homepage;
   - 1–3 genuinely relevant sibling pages.
10. Add commercial CTA only where intent supports it.
11. Affiliate links:
   https://www.vdsina.com/?partner=ni8gzrvz75
   rel="sponsored nofollow noopener"
   plus human-readable affiliate disclosure.
12. Verify provider-specific claims against current official sources.
13. Build Hugo preview.
14. Verify generated HTML:
   - exact Title/H1;
   - one H1;
   - preview noindex;
   - correct production canonical behavior;
   - JSON-LD;
   - internal routes;
   - affiliate rel attributes.
15. Open the actual built page in a browser and visually verify it.
16. Run a dense completion audit before freeze.
17. Update CHATGPT_PROJECT_CONTEXT.md and CHATGPT_SEO_AUDIT_BUFFER.md.

FINAL CLUSTER PRINCIPLE
==================================================

The homepage is the hub.
Each surrounding page must own one distinct user job.
Do not create pages just because a phrase exists.
Create a page only when SERP intent is sufficiently distinct from existing owners.

The goal is a clean hub-and-spoke structure:
Homepage -> decision/use-case/deployment/support pages -> contextual links back to homepage and only relevant siblings.

No all-to-all link farm.
No duplicate homepage variants.
No empty pages.
No claims of completion until the page is built and visually checked.
